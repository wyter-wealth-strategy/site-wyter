Quem somos

A Wyter (CNPJ {{CNPJ}}, {{CIDADE}}) é a responsável pelo tratamento dos dados pessoais descritos nesta política. Para qualquer assunto sobre dados pessoais, escreva para {{EMAIL_LGPD}}.

O que este site coleta

Este site não tem formulários, não cria contas e não usa cookies de publicidade ou de rastreamento. As fontes de letra são servidas pelo próprio site, sem chamadas a serviços de terceiros para isso.

Como todo site, o servidor que o hospeda pode registrar dados técnicos de acesso, como endereço IP, data e hora e página acessada, para segurança e funcionamento. Esses registros são mantidos pelo provedor de hospedagem.

Quando você fala conosco

Os botões de contato abrem uma conversa no WhatsApp. A partir daí, valem também os termos e a política de privacidade do WhatsApp. Os dados que você nos enviar, como nome, telefone e informações sobre sua situação, são usados para responder ao seu contato, entender sua necessidade e, se você quiser, preparar uma proposta.

Se você contratar a Wyter, os dados necessários ao serviço passam a ser tratados conforme o contrato. Também podemos guardar dados para cumprir obrigações legais.

Compartilhamento

A Wyter não vende dados pessoais. Quando o atendimento exigir parceiros especialistas, como contabilidade, direito ou seguros, compartilhamos apenas o necessário, com o seu conhecimento e com dever de sigilo.

Seus direitos

Conforme a LGPD, você pode pedir confirmação do tratamento, acesso, correção, anonimização, portabilidade, eliminação de dados tratados com seu consentimento, informação sobre compartilhamento e revogação de consentimento. Escreva para {{EMAIL_LGPD}}.

Por quanto tempo guardamos

Pelo tempo necessário para atender ao seu contato, executar o serviço contratado e cumprir obrigações legais. Depois disso, os dados são eliminados ou anonimizados.
